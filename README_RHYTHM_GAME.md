# Rhythm Game - Project Sekai Style

## Описание

Ритм-игра в стиле Project Sekai с использованием библиотеки `librosa` для анализа музыки и `pygame` для рендеринга.

## Возможности

- 🎵 **Автоматическое определение битов** с помощью librosa
- 🎮 **4 линии** как в Project Sekai
- 🎯 **Разные типы нот**: Tap, Hold, Slide
- 💫 **Визуальные эффекты** при попадании
- 📊 **Система очков** с комбо и точностью
- 🎨 **Процедурный фон** и персонажи
- 🏆 **Ранги** от S до D в зависимости от точности

## Установка зависимостей

```bash
pip install librosa pygame numpy
```

## Запуск

### Без аудио (демо режим)
```bash
python rhythm_game.py
```

### С аудио файлом
```bash
python rhythm_game.py your_song.mp3
```

Поддерживаемые форматы: MP3, WAV, OGG, FLAC и другие форматы, поддерживаемые librosa.

## Управление

- **D, F, J, K** - нажатие соответствующих линий
- **ENTER / SPACE** - начать игру / продолжить
- **ESC** - выйти из игры

## Как играть

1. Запустите игру
2. Нажмите ENTER или SPACE для старта
3. Ноты будут падать сверху вниз
4. Нажимайте соответствующие клавиши (D, F, J, K), когда ноты достигают белой линии
5. Старайтесь попадать точно для максимального комбо!

## Система очков

- **PERFECT** (±0.05 сек): 1000 + (комбо × 10) очков
- **GOOD** (±0.10 сек): 500 + (комбо × 5) очков
- **MISS** (> ±0.15 сек): сброс комбо

## Типы нот

- 🔵 **Tap** (синие) - простое нажатие
- 🟣 **Hold** (фиолетовые) - удерживайте кнопку
- 🔷 **Slide** (голубые) - быстрые последовательности

## Ранги

- **S**: 95%+ точности
- **A**: 90%+ точности
- **B**: 80%+ точности
- **C**: 70%+ точности
- **D**: < 70% точности

## Технические детали

Игра использует:
- **librosa** для анализа BPM и обнаружения битов
- **pygame** для графики и ввода
- **numpy** для обработки аудио данных

Алгоритм генерации нот автоматически создает паттерны на основе обнаруженных битов, включая:
- Одиночные ноты на основные биты
- Двойные ноты
- Длинные ноты (hold)
- Слайд паттерны

## Примечания

- Для работы требуется дисплей (X11/Wayland)
- Аудио может не работать в headless окружении
- Игра автоматически адаптируется под отсутствие аудиоустройства
